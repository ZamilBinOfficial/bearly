==================================================
                   BEARLY v1.0
  One-click Zero Mode (0% CPU, Low RAM) & Deep Clean
==================================================

HOW TO USE:
1. Extract this entire zip folder anywhere (e.g. Documents or C:\Bearly).
2. Double-click "Install.bat" (it will ask for Admin once).
3. That's it! A "Bearly" shortcut will appear on your Desktop.

FEATURES:
- Zero Mode: Stops dev processes, background junk, heavy services and flushes RAM. Restarting your PC returns everything back to normal.
- Deep Clean: Wipes temp files, shader caches, browser caches, Windows update caches in 1 click.
- Safe: Never touches Roblox, OBS, Hexa, or essential system drivers.
